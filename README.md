# SB Fusion website

Nine static pages: Home, About, Services, Hair, Beauty, Nails, Gallery, FAQ and Contact. ## Preview

Open `index.html` in a browser after extracting this package. Navigation and assets work without a build step or internet connection; external contact links require internet. A separate self-contained `SB-Fusion-Preview.html` is also supplied.

Optional local server: `python3 -m http.server 8000 --directory .`, then open `http://localhost:8000`.

No repository was created, no GitHub writes were made, and the website was not published. No enquiries or messages were sent.
